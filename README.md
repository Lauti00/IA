# IA — Actividad 9: Detector de SPAM

El notebook compara una regresión logística con escalado dentro de un `Pipeline` y un clasificador `MultinomialNB`, apropiado para las frecuencias no negativas del dataset. Incluye matriz de confusión, precision, recall, AUC y el análisis de falsos positivos y falsos negativos.

## Entorno virtual (Windows PowerShell)

Desde esta carpeta:

```powershell
py -3 -m venv .venv
.\.venv\Scripts\Activate.ps1
python -m pip install --upgrade pip
python -m pip install -r requirements.txt
```

Abrí `01_ejercicio_deteccion_spam (1).ipynb` en VS Code y seleccioná el intérprete `.venv`. El CSV debe permanecer junto al notebook.
